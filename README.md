# 🚗 Projet : Ontologie de la Mobilité

Ce dépôt rassemble les fichiers de modélisation, la documentation et les supports relatifs au projet **Ontologie-Mobilite**.

## 📌 Présentation du Projet

Cette ontologie a pour objectif de formaliser et de représenter les connaissances du domaine de la mobilité (moyens de transport, réseaux, usagers, infrastructures et services). Elle permet de structurer les données et d'assurer l'interopérabilité entre différents systèmes d'information.

## 📁 Structure des Fichiers

- **`OntMobilite.rdf`** : Fichier principal contenant la modélisation RDF/XML de l'ontologie (classes, propriétés et relations)[cite: 1].
- **`Ontologie-Mobilite/`** : Dossier contenant les ressources et sous-modules du projet[cite: 1].
- **`OntMobilite.pdf`** : Rapport documentaire décrivant la méthodologie de conception et les concepts du domaine[cite: 1].
- **`OntMobilite.pptx`** : Présentation visuelle résumant l'architecture de l'ontologie et ses cas d'usage[cite: 1].

## 🛠️ Outils Recommandés

Pour manipuler ou visualiser cette ontologie :
- **[Protégé](https://protege.stanford.edu/)** : Logiciel recommandé pour ouvrir et éditer le fichier `OntMobilite.rdf`[cite: 1].
- **Moteurs de règles / Raisonneurs** : HermiT ou Pellet (intégrés à Protégé) pour vérifier la cohérence.
- **SPARQL** : Pour exécuter des requêtes sur les données.
